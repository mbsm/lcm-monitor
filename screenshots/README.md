# Screenshots

This directory contains screenshots for the project documentation.

## Required Screenshots

1. **main_window.png** - Screenshot of the main LCM Network Monitor window showing the traffic table with multiple channels
2. **inspector.png** - Screenshot of the Message Inspector window showing the tree view of a message

## How to Add Screenshots

You can add screenshots by:
1. Taking screenshots while the application is running
2. Saving them in this directory with the names listed above
3. The README.md already references these images

## Current Screenshots
